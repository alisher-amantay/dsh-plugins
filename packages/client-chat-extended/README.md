# @alisheramantay/dsh-client-chat-extended

English | [中文](README.zh.md)

A replacement for the stock Web Chat Client plugin. It preserves the current Chat composition and suppresses the generic model-activity status while a foreground tool call already displays its exact running work. Background jobs do not suppress model activity.

The source is `@deepseek-ai/dsh-client-ui-chat` from DSH 0.2.1 with that one change, so every other Chat behavior, including opening linked files in the Web right Sidebar preview, matches the stock package. `src/` is generated by `node build/vendor-ui-chat.ts`, which copies the Harness Chat client and applies the documented edits in `CHAT_EDITS`; the vendor-drift test rejects a copy that no longer matches, so a Harness update is a regenerate-and-review step rather than a manual port.

Mount it under the existing `ui-chat` row id through `@alisheramantay/dsh-custom-bundle`.
